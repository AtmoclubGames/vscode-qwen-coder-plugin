# Инструкция по запуску Qwen Coder Bridge с прокси-сервером

## Структура проекта

```
vscode-qwen-coder-plugin/       # Плагин для VS Code
├── src/
│   └── extension.ts           # Основной код плагина
├── package.json               # Манифест плагина
└── README.md

server/                         # Прокси-сервер
├── src/
│   └── index.js               # Код сервера
├── .env.example               # Пример конфигурации
├── package.json               # Зависимости сервера
└── README.md                  # Документация сервера
```

## Шаг 1: Запуск прокси-сервера

### Установка зависимостей
```bash
cd server
npm install
```

### Создание конфигурации
```bash
cp .env.example .env
```

### Запуск сервера
```bash
# Для разработки (с авто-перезагрузкой)
npm run dev

# Или обычный запуск
npm start
```

Сервер запустится на порту 3000: `http://localhost:3000`

## Шаг 2: Авторизация в прокси-сервере

### 2.1 Получение URL для входа
Откройте в браузере или отправьте запрос:
```bash
curl http://localhost:3000/api/auth/login-url
```

### 2.2 Вход в аккаунт Qwen Coder
1. Перейдите по ссылке из ответа (https://coder.qwen.ai/)
2. Войдите в свой аккаунт Alibaba Cloud / Qwen
3. Откройте Developer Tools (F12)
4. Перейдите во вкладку **Application** → **Cookies** → **https://coder.qwen.ai**
5. Скопируйте все cookies в виде строки формата:
   ```
   name1=value1; name2=value2; name3=value3
   ```

### 2.3 Установка cookies в прокси
Отправьте POST-запрос (замените COOKIES_STRING на вашу строку):
```bash
curl -X POST http://localhost:3000/api/auth/set-cookies \
  -H "Content-Type: application/json" \
  -d '{"cookies": "name1=value1; name2=value2; ..."}'
```

Или используйте PowerShell:
```powershell
Invoke-RestMethod -Uri "http://localhost:3000/api/auth/set-cookies" `
  -Method POST `
  -ContentType "application/json" `
  -Body '{"cookies": "name1=value1; name2=value2; ..."}'
```

### 2.4 Проверка статуса авторизации
```bash
curl http://localhost:3000/api/auth/status
```

Ответ должен быть:
```json
{
  "authenticated": true,
  "message": "Авторизация активна"
}
```

## Шаг 3: Настройка и запуск плагина VS Code

### 3.1 Компиляция плагина
В отдельном терминале:
```bash
cd ..  # Вернуться в корень плагина
npm install
npm run compile
```

### 3.2 Запуск в режиме отладки
1. Откройте папку плагина в VS Code
2. Нажмите `F5` или выберите **Run and Debug** → **Run Extension**
3. Откроется новое окно VS Code с установленным плагином

### 3.3 Настройка плагина
В новом окне VS Code:
1. Откройте настройки (`Ctrl+,`)
2. Найдите **Qwen Coder Bridge**
3. Убедитесь, что:
   - ✅ **Use Proxy** = `true` (по умолчанию)
   - ✅ **Proxy Url** = `http://localhost:3000` (по умолчанию)

### 3.4 Использование плагина
1. Откройте файл с кодом
2. Нажмите `Ctrl+Shift+P` → **Qwen Coder: Start Chat**
3. Или кликните на иконку Qwen в Activity Bar (слева)
4. Введите запрос в чат и нажмите **Отправить**

## Решение проблем

### Ошибка: "Требуется авторизация"
1. Убедитесь, что сервер запущен
2. Проверьте статус: `curl http://localhost:3000/api/auth/status`
3. Если не авторизованы — повторите шаг 2

### Ошибка: "ECONNREFUSED"
- Прокси-сервер не запущен — выполните шаг 1

### Ошибка: "API ключ не настроен"
- Включите использование прокси в настройках плагина
- Или укажите API ключ DashScope (резервный вариант)

### Сервер не видит cookies
- Убедитесь, что скопировали ВСЕ cookies с домена coder.qwen.ai
- Попробуйте перезайти на сайт и скопировать cookies заново

## Дополнительная информация

### Архитектура работы
```
VS Code Plugin ←HTTP→ Proxy Server ←HTTPS + Cookies→ coder.qwen.ai
     │                    │                                    │
     │                    │                                    │
  Webview UI         Хранение сессии                    Qwen Coder API
  Чат, файлы         Cookies, логирование               Генерация ответов
```

### Преимущества прокси-сервера
- 🔐 Безопасное хранение credentials (не в плагине)
- 🍪 Работа с browser-based аутентификацией
- 📝 Логирование всех запросов
- ⚡ Возможность кеширования ответов
- 🛡️ Защита от CORS проблем

### Резервный вариант: DashScope API
Если прокси не работает, можно использовать прямой API:
1. Получите API ключ на https://dashscope.aliyun.com/
2. В настройках плагина:
   - **Use Proxy** = `false`
   - **API Key** = ваш ключ
3. Перезапустите плагин

## Контакты и поддержка

При возникновении проблем:
1. Проверьте логи сервера в терминале
2. Проверьте консоль разработчика VS Code (`Help` → `Toggle Developer Tools`)
3. Убедитесь, что обе части системы запущены
