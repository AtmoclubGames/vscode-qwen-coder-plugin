# FoodMarket-App (Пляжная доставка и Маркетплейс фермерских продуктов)

Современное веб-приложение для заказа и доставки домашней еды и фермерских продуктов на пляже / без точного адреса.

## 🚀 Архитектура проекта

Проект состоит из двух основных частей:

* **`backend/`** — Сервер на Node.js, Express, TypeScript и Prisma ORM (SQLite).
  * Управление заказами, товарами, меню вендоров и ежедневными слотами (DailyStock).
  * Маршрутизация логистики (прямая доставка `DIRECT` или через Сортировочный Центр `HUB`).
  * Телеграм и MAX мессенджер интеграции.
* **`frontend/`** — Клиентская часть на React, Vite, TypeScript и Vanilla CSS.
  * Адаптивный дизайн (Мобильная верстка + Desktop Ozon-like интерфейс).
  * Интеграция Яндекс.Карт v3 (`ymaps3`) с встроенным fallback-симулятором.
  * Мульти-ролевой интерфейс (Покупатель, Продавец/Фермер, Логист, Водитель, СММ/Админ).

---

## 🛠️ Запуск проекта

### 1. Бэкенд (`backend`)

```bash
cd backend
npm install
npm run build
npm run dev
```

*При первом запуске бэкенд автоматически сидирует базу данных (`dev.db`) первичными точками выдачи, вендорами, слотами и Сортировочным Хабом.*

### 2. Фронтенд (`frontend`)

```bash
cd frontend
npm install
npm run build
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`.

## 👥 Роли пользователей

В приложении доступна переключаемая панель ролей для удобного тестирования всех этапов цепочки:
1. **Покупатель (`CLIENT`)**: Просмотр меню по датам, корзина, выбор интервала доставки и отслеживание на карте.
2. **Фермер / Повар (`VENDOR`)**: Прием заказов на кухню, выставление статусов ("Собирается") и управление лимитами блюд.
3. **Логист (`LOGISTICIAN`)**: Формирование маршрутных листов для водителей (отправка напрямую или через Хаб).
4. **Водитель (`DRIVER`)**: Выполнение задач логистики ("В пути", "Я на месте", "Сдал в хаб" / "Выдал заказ").
5. **Администратор / СММ (`SMM_ADMIN`)**: Просмотр всей аналитики заказов, общение с клиентами в чате, редактирование новостей.
