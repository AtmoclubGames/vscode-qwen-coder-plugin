# Qwen Coder Bridge - Плагин для VS Code

Мост между Visual Studio Code и AI-ассистентом Qwen Coder (https://coder.qwen.ai/).

## Возможности

- **Чат с AI** - отправляйте запросы прямо из VS Code
- **Контекст файлов** - добавляйте файлы в контекст для анализа кода
- **Применение изменений** -一键 применять предложенные улучшения кода
- **Интеграция с редактором** - работает с активным файлом автоматически

## Установка

### Из исходников

1. Клонируйте репозиторий
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Скомпилируйте проект:
   ```bash
   npm run compile
   ```
4. Откройте в VS Code и нажмите F5 для запуска в режиме отладки

### Из .vsix файла

```bash
code --install-extension qwen-coder-bridge-0.0.1.vsix
```

## Использование

### Команды

- `Qwen Coder Bridge: Открыть чат` - открыть панель чата
- `Qwen Coder Bridge: Отправить сообщение` - отправить запрос в Qwen Coder
- `Qwen Coder Bridge: Добавить файл в контекст` - выбрать файл для анализа
- `Qwen Coder Bridge: Применить изменения` - применить предложенные изменения

### Настройки

- `qwenCoderBridge.useProxy` - Использовать прокси-сервер (рекомендуется, по умолчанию: true)
- `qwenCoderBridge.proxyUrl` - URL локального прокси-сервера (по умолчанию: http://localhost:3000)
- `qwenCoderBridge.apiKey` - API ключ для DashScope API (резервный вариант)
- `qwenCoderBridge.apiEndpoint` - URL API эндпоинта (по умолчанию: https://coder.qwen.ai/api)

## Как это работает

1. Вы открываете чат через команду или иконку в Activity Bar
2. Пишете запрос (например: "оптимизируй эту функцию" или "найди баги")
3. Плагин отправляет ваш запрос вместе с содержимым активного файла
4. Получаете ответ с предложениями по улучшению кода
5. Нажимаете "Применить изменения" для автоматического редактирования файла
